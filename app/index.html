browser-build-workshop

TS→JS と Rust→Wasm の変換専用サイト。 本体システムは置かず、ブラウザ上でコードを整理・変換・出力するための作業場として使う。

Browser Only TS → JS Rust → Wasm Smartphone Friendly

ページ一覧

TS変換ページ

TypeScriptコードを入力し、JavaScriptへ変換するページ。 複数ファイル、ログ表示、出力保存を前提にする。

  • TSコード入力
  • 補助ファイル管理
  • 変換実行
  • ログ表示
  • .js出力

Rust変換ページ

Rustコードを入力し、Wasm出力を目指すページ。 単純な1ファイル変換ではなく、ビルド寄りの作業場として作る。

  • lib.rs / main.rs 対応
  • 複数Rustファイル管理
  • Cargo相当設定
  • ビルドログ表示
  • .wasm / loader.js出力

このサイトの前提

これは本体サイトではない。変換専用の分離サイトとして運用する。 重い処理や複数ファイル対応を前提にするため、スマホでは無理をさせすぎない構成で進める。
  • 本体システムのコードは置かない
  • 変換・ビルド・出力だけに絞る
  • TS側もRust側も複数ファイル前提で進める
  • ログ、保存、ダウンロードは初期から用意する
