browser-build-workshop

TS→JS と Rust→Wasm を、サイトだけで扱うためのビルド専用作業場。 本体システムは置かず、変換と出力だけに役割を絞る。

TS → JS

TypeScript 入力、補助ファイル追加、出力名指定、変換結果確認までをまとめて扱うページ。

対象 main.ts / 補助TSファイル / 出力JS
予定機能 複数ファイル、圧縮、難読化、まとめ保存

Rust → Wasm

Rust入力、Cargo相当設定、補助Rustファイル、出力管理までを持つブラウザ内ビルド土台。

対象 lib.rs / main.rs / Cargo設定 / 補助Rustファイル
予定機能 仮想FS、依存管理、Wasm出力、JSローダー生成
